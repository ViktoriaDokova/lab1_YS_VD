# Опис компонентів проєкту

* Card.h: Структура `Card` для представлення гральної карти. Перевантажено оператор тристороннього порівняння `<=>` за рангом для зіставлення карт без урахування їхньої масті.
* CardDealer.cpp/h: Клас `CardDealer`, що відповідає за генерацію, перемішування (`std::mt19937`) та послідовну видачу карт. При вичерпанні карт у поточній колоді автоматично формується та перемішується нова.
* InputFile.cpp/h: Модуль зчитування та валідації вхідних параметрів. Забезпечує перевірку діапазонів значень і коректності формату з деталізацією помилок за номерами рядків.
* PileStatistics.cpp/h: Модуль аналізу та аналітичної обробки даних. Алгоритм розбиває видачу на строго зростаючі послідовності карт та розраховує статистичні показники (середню довжину, медіану, найчастішу довжину та процентний розподіл).
* main.cpp: Головний модуль програми. Координує зчитування конфігурації, виконання поодинокого запуску симуляції та проведення серії експериментів із виведенням результатів у файл.
* input.txt / output.txt: Текстові файли для задання вхідних параметрів запуску та збереження підсумкових даних.
